# Mastermind (Noir)

## Code Structure

- `src/main.nr`: Contains the test cases for the mastermind circuit.
- `src/circuit.nr`: Contains the mastermind circuit logic.

## Running the Examples

### Prerequisites

[Install Nargo](https://noir-lang.org/docs/getting_started_manually#installing-nargo) (v1.0.0-beta.1 or newer)

### Command Line Instructions

To run the tests
```shell
nargo test
```
